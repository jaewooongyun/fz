# v4.35.0 (2026-09-13) — 고친 검사가 같은 방식으로 다시 샜다 [MINOR]

자체 검사 13종이 전부 초록인데 통합 배선 두 곳이 몇 달째 죽어 있었다. 그것을 고쳤고,
**고치는 과정에서 같은 종류의 결함을 다시 만들었다.** 이 릴리즈에서 가장 값이 나간 것은
수리 자체가 아니라 그 재발을 적대적 검증 셋이 잡아낸 기록이다.

## 1. 이름이 어긋난 배선은 오류를 내지 않는다

`/sc:X` 형태로 부르던 외부 명령 20종이 설치본에서는 `/sc:sc-X` 다 — 순수 네임스페이스 불일치이고
20종 전부 실존한다. 에이전트 `tools:` 의 Serena 도구 이름은 런타임 규격
`mcp__plugin_<plugin>_<server>__<tool>` 와 어긋나 있었다. **86곳 · 148곳**을 고쳤다.

⛔ **왜 오류가 안 났나**가 이 항목의 핵심이다. `tools:` 는 목록이 **전부** 미해결일 때만
launch 가 실패한다. `Read, Grep, Glob` 이 살아 있으면 Serena 항목만 조용히 빠진다 —
워커 251회 실행에서 Serena 호출이 0건이었던 이유다. 공식 문서가 이 규격을 명시하고
*"a subagent's `tools` field"* 를 직접 지목한다 [verified: code.claude.com/docs/en/mcp].

## 2. 배선을 교체하면 계약이 따라오지 않는다

기본 플랜 워크플로를 교체할 때 반환 계약 넷이 함께 사라졌고 소비처는 그대로 남아
영구 no-op 이었다. 복구하면서 **스키마에 필드가 있는데 프롬프트가 요청하지 않아 죽어 있던**
다섯 번째를 찾았다. 스키마에 필드가 있다는 것과 계약이 작동한다는 것은 다르다.
⛔ 에이전트 콜은 늘지 않는다 — 렌즈는 돌고 있었고 되돌려 보내는 자리만 없었다.

## 3. 검증기 일곱 곳이 스스로 통과를 인쇄했다

`json.loads` 가 `NaN` 을 받아들여 이후 범위 비교가 **둘 다 거짓**이 되고 `GATE-PASS` 가 나오던 것,
미지원 키워드 검사가 데이터를 따라가 빈 배열 아래에 도달하지 않던 것, 렌즈 하나가 죽어도
`pass` + 완주 `3/3` 을 인쇄하던 것, 위반을 인쇄하고 `exit 0` 하던 것.

⛔ **negative fixture 를 함께 넣었다.** fail-open 은 정상 입력으로 검출되지 않는다 —
위반 입력이 막히는 것을 본 뒤에야 고쳤다고 말한다. 정상 입력도 함께 넣어 반대 고장을 본다.

## 4. ⭐ 고친 세 자리가 같은 클래스를 재생산했다

적대적 검증이 확정 결함 **9건**을 냈다. 그중 셋이 방금 고친 자리다.

| 자리 | 수리 후에도 샌 이유 |
|---|---|
| diff 크기 측정 | `awk` 의 `END` 는 입력이 비어도 0 을 찍는다 — git 실패가 "변경 0줄" 로 번역 |
| 계약 검사 블록 | `set -e` 는 **도구 셸에서 무효**다 — 실패해도 성공 토큰이 찍힌다 |
| 검증 태그 감사 | `rg` 가 이 환경에선 셸 함수라 bash 에 없다. 게다가 검사 대상이 0건 |

⭐ **공통 형태 하나로 설명된다: 측정 실패와 위반 0 이 같은 출력이다.**
이전 판은 "찾아서 인쇄하고 통과" 였고 수리 후는 "아무것도 찾지 못하고 통과" 다.
셋 다 positive control 이 없었다. 같은 저장소의 형제 스크립트가 이미 그것을 구현해 두었다.

함께 나온 것 — 상태 문자열에 새 값을 넣으면서 **그 값을 읽는 네 자리 중 둘만** 고쳐
부분 실패 경로에서 발견이 전량 유실됐다. 새로 만든 fixture 는 러너 글롭 밖이라
"회귀 오라클 12개 통과" 에 **0 기여**였다.

⛔ 이 릴리즈의 제목이 변경 자신에게 그대로 성립한다 — 초록 13개 중 이 결함들을 잡는 검사가 없었다.

## 5. 두 수치를 정정한다

- **`⛔` 총량 2,227 은 하네스 부하로 약 57% 과대**다. 상위 10 중 6개가 모델이 읽지 않는 파일이고
  스크립트의 `⛔` 는 검사 항목 표의 문자열 리터럴이다. 컨텍스트 적재분은 약 1,070 이다.
- **"floor +89%/6주" 는 근거가 성립하지 않는다.** `floor` 개념은 07-31 커밋이 도입했고
  기준선은 07-25 다 — 다른 자로 잰 두 값의 차다. 깨끗한 것은 09-06→09-13 의 **+8.3%** 뿐이다.

## 6. 하지 않은 것

- **effort 일괄 하향.** 전 호출 `xhigh` 이고 공식 출발점은 `high` 지만, 45곳을 한 번에 내리는 것은
  방향만 반대일 뿐 같은 종류의 미측정 결정이다. 노이즈 바닥부터 잰 뒤 스테이지별로 정한다.
- **마커 감량.** 적대 판정은 "규칙 *내용*이 아니라 **싣는 구조**가 과하다" 이고,
  죽은 것으로 분류된 것들은 조건 소멸이 아니라 **애초에 지시가 아닌 제목 장식**이었다.
  처방은 규칙 삭제가 아니라 어휘 정리이며, 그것을 다 해도 부하는 거의 줄지 않는다.
