## 쓰는 쪽에서 달라지는 점

- 위생 검사 기본 모드가 넓어졌다. 새 엔트리는 대기열 표 끝 행과 status 줄이 있어야 하고, 셸 출력은 펜스 안에 둔다. 출력 표지 `[--strict] …` 는 기본 모드에서도 그대로 찍힌다.
- review · peer 응답은 schemaVersion 1.1 만 받는다.
- GPT 호출은 900초 동안 출력이 없으면 끊긴다. `FZ_GPT_IDLE_SEC` 로 바꾸고, 0 이면 끈다.
- Tier 자동 선택에서 BASE 가 없을 때도 TIER=2 가 남는다. 이전에는 바로 아래 자동 판정이 TIER=0 으로 덮었다. `--tier` 를 주면 그대로 우선한다.
- 문서를 지우고 코드를 더한 PR 은 risk_scan 의 risk 와 tier_delta 가 오를 수 있다. `--json` 의 `files` 는 삭제 파일을 하나씩 센다.
- gather 에 `--base <원격>/<브랜치>` 를 주면 원격 선택을 건너뛰고 그 브랜치로 신선도를 잰다.
- 회귀 러너는 `FZ_BASE_*` 를 읽지 않는다. 옛 이름만 있으면 WARN 을 내고 기본값으로 돈다.
- `rg` 는 tool-inventory 에 선언하지 않는다(사용자 결정 2026-10-09). 선언하면 문서에 다시 들어온 `rg` 가 lint 를 통과한다. `gh` 선언은 유지한다.
