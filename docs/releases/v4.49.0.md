# v4.49.0 (2026-11-01) — 차단 목록으로 지은 근사기는 리뷰마다 새 구멍이 났다 — Stop 훅 소유 판정을 허용 목록으로 바꾸고, 원장 · 레지스트리의 '모르면 통과' 를 닫는다 [MINOR]

Stop 훅은 세션이 쓴 원장만 판정해야 하는데, `for L in …` 루프로 원장을 넘기면 루프 변수를 못 풀어 남의 원장까지 판정했다(F-457). 루프 값을 풀자 이번엔 '지원 밖 꼴' 목록에 없는 셸 꼴마다 실제로 쓴 원장을 남의 것으로 보고 통과시켰다 — GPT 리뷰가 8 라운드 내리 새 꼴을 냈다(F-458). 그래서 '풀었다' 판정을 허용 목록으로 뒤집고, 모르는 꼴은 '대상 미상'(전 원장 판정)으로 둔다.
같은 축의 계약 공백 셋을 닫았다 — 환경 변수가 없어 CHECK 를 못 돌린 게이트가 통과 증거를 잃던 것(F-342) · 통과 뒤 도구가 사라져도 `--status` 가 met 이던 것(F-291 의 TOOLS 축) · 엔트리 본문에 남은 작성 명령을 위생 검사가 못 보던 것(F-456).
