# v0.58.0 (2026-11-23) — 알던 셸 함정을 가드가 경고하고, 검사기가 수 · 인용 · 출하 대상을 확인한다 [MINOR]

기록해 두고도 다시 밟던 셸 함정을 fz-guard 가 경고한다. 검사기들은 '표지가 있다' 만 보던 자리에서 대조값 · 인용 줄 · 출하 커밋을 직접 잰다.

닫은 finding 없음.

## 갱신하는 법

```bash
claude plugin marketplace update fz-orchestrator
claude plugin update fz@fz-orchestrator
claude plugin update fz-guard@fz-orchestrator     # 설치했을 때만 — 0.5.0
```

## 주요 변경

- **fz-guard** — 검색 명령 뒤 `| head`, 맞는 파일이 없을 수 있는 글롭, `cd X &&` 를 prompt 마다 한 번 경고한다. 막지는 않는다
- **계획 검사** — 한 칸에 경로를 여럿 묶으면 실패한다. '0건 · 없다' 주장에 대조값이 없으면 경고한다
- **리뷰 검사** — 전제가 한정된 후보에 실측 확인을 요구하고, 산문의 `path:line` 인용을 원문과 대조한다
- **GPT 판정** — 끝맺는 한국어 부재 문장만 통과로 읽는다. '확인하지 못했다' 로 끝나는 문장은 통과가 아니다
- **출하 대조** — `check_release_closes.py --expect-ref` 가 검사한 저장소가 출하 커밋인지 먼저 본다

## 알아 둘 것

- fz-guard 경고는 `FZ_GUARD_DISABLE=all` 로만 꺼진다 — 다른 규칙도 함께 꺼진다
- 얕은 clone 에서 `review --base` 는 공통 조상이 없으면 exit 11 로 멈춘다
