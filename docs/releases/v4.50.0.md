# v4.50.0 (2026-11-02) — GPT 단계를 한 줄로 판정하고, 재검증 라운드에 상한을 두고, 쓰이지 않는 하네스를 걷었다 [MINOR]

GPT 를 부를지가 스킬마다 산문으로 갈렸다. 이제 모든 GPT 단계는 직전에 `gpt-choice.sh decide` 한 줄로 정하고, 같은 산출물의 재검증은 정문이 세어 네 번째부터 막는다.
31일 대화 기록에서 쓰이지 않은 의무와 장치는 걷거나 선택으로 낮췄다. 출하 전 리뷰가 찾은 결함도 이 판에서 고쳤다.

> ⛔ **올린 뒤 세션을 다시 시작한다.** 새 에이전트 `arch-lens` 는 새 세션에서만 등록된다. 옛 세션에서 새 워크플로를 부르면 그 렌즈가 스폰 전에 실패한다.

## 쓰는 쪽에서 달라지는 점

- fz-fix 의 GPT check 는 GPT 를 켠 세션이면 필수다. `--gpt` 인자는 없어졌다
- 같은 산출물에 네 번째 GPT 검증을 부르면 exit 19 로 거부된다. 미해결로 보고하고 다시 돌리지 않는다
- fz-plan full 은 독립 GPT 계획을 기본으로 띄운다. 끄려면 `--no-gpt-independent`
- 작업 폴더 없이 쓰는 세션은 `WORK_DIR=` 빈 값으로 부르면 세션 원장에 센다
- 세션 복원은 티켓 폴더의 `index.md` 다. `/sc:sc-save` · `/sc:sc-load` 는 선택이다
- `bash scripts/health-check.sh --changed <경로>` 는 바뀐 곳만 본다 — 출하 게이트가 아니다

## 출하 전 리뷰에서 고친 것

GPT 리뷰와 Claude 교차 리뷰가 찾은 결함을 고쳤고, 고친 뒤 GPT 역방향 검증에서 26건 모두 해결로 판정됐다.

| 영역 | 고친 것 |
|---|---|
| 재검증 라운드 | 작업 폴더 없는 세션이 셸 오류로 멈추던 것 · 저장소 안 판정 파일이 같은 입력 판정을 피하던 것 · 상한 거부가 마지막 판정 파일을 지우던 것 |
| 후보 만료 판정 | 하위 조치의 DEFERRED 를 항목 상태로 읽던 것 · 아래 줄의 '카운트 미반영' 을 놓치던 것 |
| 텔레메트리 | peer-review counter 의 새 지적이 0으로 집계되던 것 |
| 검사기 | 모르는 lint 이름이 PASS 로 끝나던 것 · 깨진 원장이 '차이 있음' 으로 읽히던 것 |
| 문서 | 실제와 다른 배선 표기 · 선택이 된 sc 명령을 요구하던 절차 · 상한 재서술 · 낡은 수치 |
