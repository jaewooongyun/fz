> 자동으로 5.5 를 가리켰다 — 모델 이름에 **기대는** 곳(단가표·lint 어휘·문서 사실)은 따라가지 않았다.

## 1. 무엇이 문제였나

- **텔레메트리가 틀린 값을 조용히 냈다.** `price_for()` 는 모르는 모델 ID 를 접두 일치로 가까운 단가에 붙였다. `claude-opus-5-5` 는 `claude-opus-5` 로 떨어져 Opus 5 단가 `(5.0, 10.0, 0.5, 25.0)` 을 받았다(base 커밋 실측). 오류가 나지 않았던 이유가 곧 결함이다 — 폴백이 "그럴듯한 값" 을 돌려줬다. 2026-09-22 이후 리포트는 입력·출력·1h 캐시 쓰기 **×1.25**, 캐시 읽기 **×2.5** 과다 계상.
- **최신성 lint 가 구세대를 못 봤다.** `LEGACY_MODELS` 에 `Opus 5` 가 없었고, 넣으면 `Opus 5` ⊂ `Opus 5.5` 부분문자열 충돌로 현행 표기까지 잡는다.
- **워커가 advisor 를 상속한다.** 끄는 네이티브 수단이 없다 — 워크플로 프롬프트 문구뿐인데 8개 중 4개가 빠져 있었다.
- **GPT 표면에 codex 명칭과 raw CLI 예시가 남아 있었다** — 래퍼(`gpt-exec.sh`)가 막는 hang·sandbox·인자 충돌을 문서 예시는 그대로 보여줬다.
