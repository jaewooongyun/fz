# v4.39.0 (2026-09-25) — 별칭은 새 모델을 따라갔고 단가표는 따라가지 않았다 [MINOR]

## 문제

2026-09-22 Claude Opus 5.5·GPT-6 Sol 이 나왔다. `opus` 별칭은 Claude Code 2.1.280 에서 자동으로 5.5 를 가리켰지만,
**모델 이름에 기대는 세 곳**은 따라가지 않았다.

- **텔레메트리** — `claude-opus-5-5` 를 Opus 5 단가로 계산했다. 09-22 이후 리포트는 입력·출력 ×1.25, 캐시 읽기 ×2.5 과다
- **최신성 lint** — Opus 5 를 현행으로 봐서 구세대 표기를 찾지 못했다
- **문서** — 워커 모델·가격·breaking·effort 기본값이 Opus 5 기준이었다

## 원인

- **이름 기반 폴백** — 모르는 모델 ID 를 접두 일치로 가까운 단가에 붙였다. 오류 없이 틀린 값이 나와 드러나지 않았다
- **문구로 확인한 전제** — 작업 중 세 전제가 실측으로 뒤집혔다. 게이트 통과가 캐시였고(F-307), effort 를 빼면 세션 값이 아니라 워커 모델 기본(`medium`)으로 떨어졌고(F-308), `--add-dir` 은 읽기가 아니라 쓰기 디렉토리 플래그였다(F-309)
