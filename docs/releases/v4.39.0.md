## 1. 무엇이 문제였나

- **텔레메트리가 틀린 값을 조용히 냈다.** `price_for()` 가 모르는 모델 ID 를 접두 일치로 가까운 단가에 붙여 `claude-opus-5-5` 를 Opus 5 단가로 계산했다. 오류 없이 그럴듯한 값이 나와 드러나지 않았다 — 09-22 이후 리포트는 입력·출력 ×1.25, 캐시 읽기 ×2.5 과다
- **최신성 lint 가 구세대를 못 봤다.** `Opus 5` 를 현행으로 봤고, 구세대로 넣으면 `Opus 5` ⊂ `Opus 5.5` 부분문자열이 현행 표기까지 잡는다
- **문서 사실이 Opus 5 기준이었다.** 워커 모델·가격·breaking·effort 기본값
- **워커가 advisor 를 상속한다.** 끄는 네이티브 수단이 없는데, 금지 문구가 워크플로 8개 중 4개에 빠져 있었다
- **GPT 표면에 옛 CLI 호칭과 raw CLI 예시가 남아 있었다.** 래퍼가 막는 hang·sandbox·인자 충돌을 문서 예시는 그대로 보여줬다
