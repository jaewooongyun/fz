# v4.37.0 (2026-09-15) — 참조 탐색이 63%를 놓치고 있었다 [MINOR]

프로토콜 메서드의 구현체를 찾지 못하는 도구를 영향 반경 분석의 Primary 로 쓰고 있었다.
전수 측정으로 확인하고 codegraph 로 옮겼다.

**실측** — `Apps/Sources` 프로토콜 메서드 **1,828건** 전수(헤드리스 Serena 직접 호출, 22분).
동명이인을 배제한 층(N=468)에서 `find_referencing_symbols` **recall 36.9%** · precision 99.5% ·
0건 반환 19% · 호출 에러 10.3%(Swift 오버로드 `ValueError`). 같은 질문에 codegraph 는 **88.8%** 다.

**기전** — LSP `textDocument/references` 는 "이 선언을 참조하는 위치"를 답한다. Swift 에서
프로토콜 요구사항과 그 conformance 구현은 **서로 다른 선언**이라 참조 관계가 아니다.
손검증: `LiveDetailPresentable/bindCategory` 는 ViewController 가 채택·구현하는데 0건이 나온다.

**층이 갈린다** — 같은 서버의 다른 도구는 멀쩡하다. `find_symbol` 99.8% ·
`get_symbols_overview` 100%(N=1,188 전수) · 편집 도구가 쓰는 심볼 경계 10,459건 전건 일치.
망가진 것은 references 에 기대는 도구뿐이라 **그 층만** 교체했다.

**⛔ 에이전트 층 측정은 무효였다 (2026-09-17 정정)** — 초판은 널리 분산된 케이스에서
워커가 **6.1%** 로 무너진다고 적었으나, 그 정답표의 **89% 가 동명이인**이었다.
`popViewController`·`evaluateJavaScript`·`detachChild` 는 각각 UIKit·WKWebView·RIBs 의
표준 API 와 동명이라 텍스트 매칭이 무관한 호출을 전부 긁었다(28곳 중 25곳이
`navigationController?.popViewController`). 프로토콜 **선언** 파일까지 걸러낸 진짜 정답은
4곳이고 워커 답과 정확히 일치한다 — **recall 100%**.

**그래서 교체의 실효는 정확도가 아니라 탐색 효율이다.** 동명이인이 없는 변별 문항 4개
(같은 질문에 Serena 0% · codegraph 100%)에서 워커는 **recall 100% · precision 100% 를
도구 호출 8회**로 낸다. 오염 문항에서 같은 만점을 내는 데는 Grep 22~27회가 들었다.
⭐ 워커는 매번 `noisy output`·`different protocol entirely` 라고 이유를 적어 두었는데,
네 번의 측정 동안 그것을 워커의 실패로 읽었다. 측정과 에이전트가 충돌하면 측정을 먼저 의심한다.

#### 변경

- **배선 교체** — agents 10 + skills 9 에서 Primary 를 `mcp__codegraph__codegraph_explore` 로.
  `find_referencing_symbols` 는 **폴백으로 강등 보존**한다(codegraph 미설치 소비자의 degrade 계약).
- **0건 교리 SSOT** — `plan-impact`·`plan-deep-planning` 의 "참조 0 → dead code 후보" 지시를
  제거하고 `cross-validation.md` § Negative-Result Gate 로 수렴. 함정 표에 LSP references 행과
  stale 게이트 명령을 추가했다. `review-quality` 의 Few-shot 방어는 보존(트리밍 비저하).
- **`rename_symbol` 배선 제거** — dry-run 실측에서 프로토콜 메서드 이름 변경 시 편집 대상이
  선언 1파일뿐이고 구현부를 빠뜨린다. 표 행은 삭제가 아니라 **대체 절차로 치환**했다.
- **stale 게이트 신설** — `scripts/check_codegraph_fresh.py`(sha256 대조, self-test 4종).
  `health-check.sh` 필수 목록에 등재. 인덱스 부재는 **UNRUN(exit 2)** 이며 통과가 아니다.
  fixture `tests/fixtures/codegraph/stale-gate/run.sh` 는 동기·stale·UNRUN·self-test 4종을 돈다.

#### 알려진 제약

- **에이전트 정의는 세션 시작 시 로드된다.** 세션 중 `tools:` 편집은 그 세션 워커에 반영되지
  않는다(추가한 도구는 안 오고 제거한 도구는 계속 온다 — 양방향 실측). 배선 변경의 런타임
  검증은 **새 세션에서** 해야 한다.
- codegraph 는 플러그인이 공급하지 않는다. 인덱스가 없는 환경은 폴백(Serena·Grep)으로 동작한다.
