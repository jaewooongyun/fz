# v4.46.0 (2026-10-13) — GPT 호출을 정문 하나로 모으고, 여러 각도로 부르는 실험을 잴 계기를 넣었다 [MINOR]

fz GPT 다각도·통합 계획(2026-10-12)의 첫 두 판(R-G1 · R-G2)이다. 문서마다 손으로 조립하던 GPT 호출을 정문 하나(`scripts/gpt-call.sh <kind>`)와 레지스트리로 모았고, GPT 를 질문 틀이 다른 별도 호출로 더 부르는 것이 결함을 더 찾는지 잴 계기(실험 frame · 호출 감사 · N-way 병합 · 판정기)를 넣었다. 기본 동작은 바뀌지 않는다 — 실험 kind 는 `--experimental` 로만 돌고, 측정(R-G3)은 사용자가 사전등록을 동결한 뒤에 한다.

Closes: F-431-plain-wrapper-gpt-spawns-forked-subagents-unaudited

| 독립 런처 정책 | 런처가 역할 · 스키마 · spawn 문장을 하드코딩했다 | resolver 가 레지스트리에서 답한다 — 기본 프롬프트는 바이트가 같다 |

## 쓰는 쪽에서 달라지는 점

- GPT 호출은 `"${FZ_PLUGIN_ROOT}/scripts/gpt-call.sh" <kind> …` 로 쓴다. 문서의 래퍼 · 런처 직접 호출은 health-check 의 소비자 lint 가 막는다.
- 정책 플래그(`--schema` · `--inject-skill` · `--gpt-skill(-path)` · `--ephemeral` · `--sandbox` · `-c` · `-p` · `--profile` · `--ignore-user-config` · `--config-permissions`)를 정문에 넘기면 10 이다.
- 독립 kind(independent-review · independent-plan)에 `--timeout` 을 넘기려면 `--experimental` 이 필요하다(측정 전용).
- fz-gpt 스킬의 `Bash(codex *)` 권한이 빠졌다.
- 텔레메트리 폴더에 `gpt-calls.tsv` 가 새로 생긴다. 기존 `gpt-skill-usage.tsv` 9열은 그대로다.
- 정문을 배경(`&`)으로 띄우면 INT 가 무시된 채 들어오므로 중단은 TERM 으로 보낸다.

## 하지 않은 것

- 기본값 변경은 없다 — 실험 kind 와 frame 은 기본 흐름에 없다.
- 독립 런처의 spawn 도구 끄기(F-436) — 격리 홈 실측은 verified(`[agents] enabled = false`)지만, 배선은 측정(E1) 뒤 별도 결정이다.
- 일반 래퍼 경로의 spawn 끄기 — 감사만 넣었다.
- 측정 E1 과 판정(R-G3) — 사용자가 사전등록을 동결한 뒤에 한다.
