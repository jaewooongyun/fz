# v0.57.0 (2026-11-22) — 누수 검사를 커밋 · 태그 · 릴리스 본문 · push 까지 넓히고, 쓰이지 않던 하네스를 걷었다 [MINOR]

이전 누수 검사는 작업 트리의 파일 내용만 봤다. 이 판은 규칙을 정본 모듈 하나(`scripts/leak_rules.py`)로 모으고, 커밋 훅 · 새 push 훅 · 출하 게이트 · 릴리스 본문 검사가 같은 규칙으로 커밋 신원 · 메시지 · 태그까지 본다. 함께 가드 · 종료 게이트 · GPT 격리의 빈틈을 고치고, 불린 적 없는 기능을 걷고, 사전 승인을 조회 명령으로 좁혔다.

⛔ 공개 저장소의 이력을 이 판에서 새로 시작했다. 옛 태그와 릴리스는 없다. 판 번호도 0.57.0 으로 다시 매겼다 — 4.x 보다 낮은 번호지만 아래 순서대로 갱신하면 넘어온다.

닫은 finding 없음 — 내부 추적 번호는 공개 노트에 적지 않는다.

## 갱신하는 법

마켓플레이스를 먼저 갱신한다. 플러그인만 갱신하면 "이미 최신" 이라고 나온다.

```bash
claude plugin marketplace update fz-orchestrator
claude plugin update fz@fz-orchestrator
claude plugin update fz-guard@fz-orchestrator     # 설치했을 때만 — 0.4.0
claude plugin update fz-compact@fz-orchestrator   # 설치했을 때만 — 0.1.1
```

- 그래도 옛 판이면 마켓플레이스를 지우고 다시 더한 뒤 설치한다(`plugin marketplace remove` → `plugin marketplace add` → `plugin install`).
- 저장소를 복제해 `--plugin-dir` 로 쓰면 다시 복제한다. 이력이 이어지지 않아 pull 이 되지 않는다.
- 확인한 Claude Code 판은 2.1.325 · 2.1.328 이다. 이 판은 플러그인 뿌리에 `hooks/hooks.json` 을 처음 둔다.

## 주요 변경

- **누수 검사** — 커밋 훅이 CHANGELOG · 릴리즈 노트 · 작업 로그도 예외 없이 본다. push 훅(`.githooks/pre-push`)이 새로 생겼다. 출하 게이트(`check_release_sync.sh --release`)는 커밋마다 신원 · 메시지 · 추가 줄과 태그를 보고, `--rules <파일>` 을 명시로 요구한다
- **실행 기록** — 저장소 밖(`${FZ_RUN_STATE:-~/.fz/runs}`)에 쓴다
- **예시 · fixture** — 합성 '주문 앱' 도메인 하나로 바꿨다
- **걷은 것** — SuperClaude 지시 · Serena 체크포인트 · GPT 역할 스킬 둘(fz-fixer · fz-searcher) · GPT kind 셋(`search` · `fix-suggest` · `openai-docs`) · `--gpt-agents` · 옛 판 릴리즈 노트 파일
- **사전 승인** — 조회 꼴로 좁혔다. 쓰기 명령(`git commit` · `git push` · `gh pr create` 등)은 이제 권한을 묻는다. GitHub 는 `gh` CLI 로만 다룬다
- **fz-guard** — Phase 4 승인 전에도 읽기 명령 몇 꼴(awk 정규식 · `print` · `case` · 판정기 조회)은 통과시키고, 에이전트 확인 창은 알림 한 줄로 바꿨다
- **종료 게이트 훅** — 같은 상태로는 한 번만 막고, 이 세션이 쓴 뒤 바뀐 원장만 본다
- **GPT** — 로그인하지 않은 머신에서는 GPT 단계를 '미사용' 으로 건너뛴다. 대화 세션은 마지막 모델 · effort 선택을 이어 쓴다
- **워커 심볼 도구** — 플러그인 종료 훅이 턴마다 워커가 심볼 도구를 썼는지 세고 기록한다. 막지 않는다(`FZ_MCP_SWEEP_OFF=1` 로 끈다)
- **`/fz-pr`** — 프로젝트 규칙에 fork 규칙이 있을 때만 fork → upstream 으로 안내하고, 없으면 같은 저장소에 PR 을 연다
- **판 폴더 고르기** — 훅 예시 · 등록 안내 · GPT 스킬 설치 명령이 캐시에서 번호가 가장 높은 폴더 대신 설치 기록(`installed_plugins.json`)의 설치 경로를 읽는다. 갱신 뒤 캐시에 남은 옛 4.x 폴더를 고르지 않는다
