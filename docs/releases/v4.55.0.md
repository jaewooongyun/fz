## 쓰는 쪽에서 달라지는 점

- fz-guard 0.3.0 은 `FZ_GUARD_PROTECTED` 나 상태 폴더의 `protected` 파일에 적은 경로 아래에서 도는 Bash 를 묻는다. 둘 다 비어 있으면 아무 일도 없다
- fz-plan light 가 GPT 독립 플랜을 기본으로 띄운다. 끄려면 `--no-gpt-independent` 를 준다
- health-check 러너는 `SETUP` 표지가 있는 exit 3 만 미실행으로 센다. 미실행이 남으면 게이트가 통과하지 않는다
- `/fz-gpt check` 판정에 `unrun` 이 생겼다. 파일이 없거나 판정 신호가 없는 출력은 지적 0 으로 읽지 않고 본문을 읽게 한다
- 원장 생성(`gate_check.py --from-plan`)이 플랜의 `timeout` 과 `side_effects` 를 원장 `TIMEOUT` · `SIDE_EFFECTS` 로 옮긴다
- 릴리스 동기 검사의 중립화 축은 fz 스키마가 정한 지적 id(`ISSUE-NNN`)를 사내 티켓 키로 세지 않는다
