# v4.47.0 (2026-10-15) — 질문 틀을 바꿔 GPT 를 한 번 더 부르는 것은 같은 질문을 반복한 것과 같았다 — 반증 틀 리뷰를 뺐다 [MINOR]

fz GPT 다각도·통합 계획의 세 번째 판(R-G3)이다. v4.46.0 이 넣은 계기로, 질문 틀을 바꾼 두 번째 GPT 리뷰(반증 틀 `review-falsify`)가 같은 질문을 한 번 더 부른 것보다 결함을 더 찾는지 사전등록 실험(E1)으로 쟀다. 비교한 7개 과제 모두에서 더 찾은 critical·major 결함이 0개라 판정은 ROLLBACK 이고, 이 판에서 그 실험 kind 를 뺐다. 기본 흐름은 바뀌지 않는다.

Closes: 없음 — 측정이 드러낸 계측 구멍 F-440 ~ F-444 는 열어 둔다
