## 1. fixture 이식성 결함

fixture 원장의 `ROOT:`·`CWD:` 는 커밋한 사람의 클론 경로다. self-test 가 sandbox 로 재작성하는데 `replace(str(FIXTURES), …)` 만 썼다. 다른 클론이나 플러그인 캐시에서는 `FIXTURES` 가 그 경로와 달라 매칭이 0건이 되고, ROOT 가 남의 경로를 가리켜 소유 검사에서 전부 exit 3 이 된다.

```
캐시에서 self-test        19/66
임시 디렉토리 복사본       19/66
개발 모드(--plugin-dir)   66/66   ← 여기서만 통과해 안 보였다
```

⛔ **개발 모드로만 쓰면 드러나지 않는 결함이었다.** 플러그인을 실제로 설치해 캐시에서 돌려야 보인다.

경로 **모양**으로 재작성한다 — `…/tests/fixtures/gates` 로 끝나는 절대 경로를 sandbox 로 바꾼다.

**오라클**: 저장소를 임의 위치로 복사해 self-test. 음성 대조로 옛 형태를 되돌리면 19/66 재현. 매니페스트 `_notes.fixture-portability` 에 회귀 확인 방법 기록.

## 2. hook 설치 주의 7항

hook 은 fail-open 이라 잘못 설치해도 에러가 안 난다. 그래서 설치 실패가 **무증상**이다.

| # | 주의 |
|---|------|
| 1 | `hooks.Stop` 은 배열 — 통째로 복사하면 기존 항목이 사라진다 |
| 2 | hook 은 **병렬**로 돈다. 여러 Stop hook 의 block 합산 규칙은 공식 문서에 없다 `[미검증]` |
| 3 | 캐시 경로에 **버전이 들어간다** — 하드코딩하면 업데이트 후 조용히 꺼진다 |
| 3b | ⛔ **개발 모드는 캐시 경로 형태로 절대 안 돈다** — 소스 우선 폴백을 쓴다 |
| 4 | `python3` 3.9+ 부재 시 fail-open. 설치 후 `--self-test` 로 확인 |
| 5 | `~/.fz/stop-hook-state.json` 을 만든다 (무한 루프 방어 카운터) |
| 6 | 원장 탐색은 CWD 하위 깊이 3 — 워크트리면 `FZ_GATES_LEDGER` |
