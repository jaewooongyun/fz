# 선택 도구 상태 — 알리는 형식

> 적용: frontmatter 의 allowed-tools 에 선택 도구(Serena · context7 · sequential-thinking)가 있는 스킬 — 첫 단계에 알린다.

- 꼬리: ` · context7 목록✓|목록✗ · sc 목록✓|목록✗`. ✗ 가 하나라도 있으면 ` — 빠지는 단계: <그 도구로 하던 단계>` 를 붙인다(✓ 뿐이면 붙이지 않는다)
- `목록✓` = Lead 의 도구 목록에 그 이름(context7 MCP 도구 · `sc:` 로 시작하는 스킬)이 있다 — 연결됐다는 뜻이 아니다. 목록만 보고 적는다(확인용 호출 없음)
- 작업 폴더 프로필(peer-review · plan · discover · fix): `evidence/tools.md` 첫 줄의 Serena 부분 뒤 **같은 줄**에 꼬리를 붙인다. 예: `[Serena 미사용 — 비 git 작업 폴더] · context7 목록✗ · sc 목록✓ — 빠지는 단계: 라이브러리 문서 조회`
- 나머지 스킬: 화면 한 줄 `[선택 도구] Serena 목록✓|목록✗` + 꼬리
- 오케스트레이터(`/fz`)는 승인(Phase 4) 전에는 화면에만 알린다(승인 전 쓰기는 가드가 막는다) — 파일 기록은 승인 뒤다
