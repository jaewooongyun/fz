# 워커 심볼 도구 점검 — 출력 낱말과 할 일

> 적용: `fz_wf_metrics.py --mcp-audit` 를 돌린 뒤에 읽는다. 명령 꼴 셋과 워커를 띄우기 전의 끔 신호 규칙은 `modules/tool-status.md` § 워커 심볼 도구에 있다.
> 판정은 호출 수가 아니라 결과를 돌려준 호출 수로 낸다 — 부르기만 하고 오류뿐인 실행은 통과가 아니다.

## 출력 낱말

| 낱말 | exit | 뜻 | Lead 가 할 일 |
|---|---|---|---|
| `MCP_AUDIT_OK` | 0 | 결과를 돌려준 심볼 호출이 1 이상(성공 · 오류 · 빈 결과 수를 함께 찍는다) | 그대로 진행한다 |
| `MCP_FALLBACK` | 0 | 호출 0 · 상태 기록이 미사용(기록된 사유를 찍는다) | 진행한다. 결과 보고에 미사용 사유를 한 줄 적는다 |
| `MCP_FALLBACK_UNCOVERED` | 0 | 성공 0 · 결과가 온 호출이 있고, 결과가 없는 호출까지 물은 파일이 전부 켜진 언어 밖(켜진 언어 목록을 찍는다) | 진행한다. 그 파일 종류의 근거는 글자 검색이다 |
| `MCP_NOT_APPLICABLE` | 0 | 심볼 도구를 가진 종류의 워커가 없다 — 판정할 것이 없다(일반 모드만 · 에이전트 정의에 있고 심볼 도구가 없는 종류를 빼고 뺀 종류를 찍는다) | 그대로 진행한다 |
| `MCP_WIRING_SUSPECT` | 1 | 호출 0 인데 `Read` 는 있다 · 상태 기록이 활성 | 아래 'exit 1 일 때 볼 것' |
| `MCP_CALLED_NO_RESULT` | 1 | 성공 0 · 켜진 언어의 파일을 물은 호출이 오류로 돌아왔다 | 아래 'exit 1 일 때 볼 것'. 심볼 서버가 대상 트리에서 그 언어로 떠 있는지(상태 기록의 트리 · 언어 목록) 다시 확인한다 |
| `MCP_STATE_MISMATCH` | 1 | 상태 기록은 미사용인데 워커가 심볼 도구를 불렀다 | 끔 신호 줄이 빠졌거나 기록이 틀렸다 — 기록을 다시 적거나, 다음 호출의 입력 끝에 끔 신호를 붙인다 |
| `MCP_OTHER_TREE` | 1 | 워커가 다른 트리 표지(`[symbol tools: unavailable - not on the target tree]`)를 남겼다 | 대상 트리에서 심볼 서버를 다시 켜고 상태 기록을 고친다. 표지는 글자로 맞춘다 — 워커가 표지를 인용만 해도(검토 대상이 이 플러그인 자신일 때 생긴다) 찍히므로 따르기 전에 그 워커의 보고를 읽는다 |
| `MCP_UNDECIDED` | 2 | 성공 0 · 파일을 지정하지 않은 찾기 · 폴더 · 켜진 언어 파일의 빈 결과가 남았다 · 결과가 온 호출은 전부 켜진 언어 밖인데 결과 없이 남은 호출이 켜진 언어 파일이나 불명 대상을 물었다 · 결과가 온 호출이 없다(기록이 중간에 끊겼다) | 통과 아님 — 미판정으로 보고한다 |
| `UNRUN` | 2 | 판정할 수 없다 — 출력 줄이 이유를 적는다(실행 기록 · 상태 기록을 못 읽음 · 도구 작업 0 · 대조 `Read` 0 · 호출 0 · `Read` 있음인데 상태 기록이 없음 · 성공 0 인데 상태 기록이 없거나 언어 이름이 확장자 표에 없음 · `--direct` 에 맞는 세션 폴더가 하나가 아님 등) | 통과 아님 — 아래 'exit 2 일 때 볼 것'. 인자로 고칠 수 있으면(`--tools-md` · `--session` · `--wf`) 고쳐 다시 돌리고, 아니면 미판정으로 보고한다 |
| `ARM_SYMBOL_USED` | 0 | 탐색 팔: 결과가 돌아온 호출 1 이상 | 결과에 `[심볼 팔: serena 성공 N회]` 를 싣는다 |
| `ARM_CALLED_NO_RESULT` | 0 | 탐색 팔: 불렀으나 전부 오류 · 빈 결과 | 결과에 `[심볼 팔: 글자 검색 폴백 — serena 를 불렀으나 결과가 없었다 · 두 팔이 같은 방법이다]` 를 싣는다 |
| `ARM_OTHER_TREE` | 0 | 탐색 팔: 워커가 다른 트리 표지를 남겼다 | 결과에 `[심볼 팔: 글자 검색 폴백 — serena 가 다른 트리에 떠 있었다 · 두 팔이 같은 방법이다]` 를 싣는다 |
| `ARM_TEXT_ONLY` | 0 | 탐색 팔: 호출 0 | 결과에 `[심볼 팔: 글자 검색 폴백 — 두 팔이 같은 방법이다]` 를 싣는다 |

- 심볼 호출은 Serena 의 심볼 읽기 도구 다섯(`find_symbol` · `find_referencing_symbols` · `get_symbols_overview` · `find_implementations` · `find_declaration`)뿐이다. 메모리 · 프로젝트 활성 · 설정 · 안내 등 그 밖의 Serena 도구는 호출 수에도 도구 작업에도 성공 · 오류 · 빈 결과에도 세지 않고 정보 줄(도구 이름별 수)로만 찍는다.
- 탐색 팔(`--only-label`)은 보고 모드다 — 경보가 아니라 표지를 고르는 데 쓴다. 탐색 팔의 `UNRUN`(라벨을 못 읽은 워커가 있다 · 그 라벨의 워커가 없다)이면 표지를 싣지 않고 판정하지 못한 사실을 결과에 적는다.
- 직접 호출(`--direct`)은 그 에이전트 종류의 가장 최근 호출 하나만 판정하고 앞선 호출은 정보 줄로만 찍는다 — 같은 종류를 두 번 띄웠으면 한 번 끝날 때마다 돌린다.

## exit 1 일 때 볼 것

1. 이 실행이 코드 심볼을 다뤘는가 — 문서 · 설정만 읽은 실행이면 호출 0 이 정상이다. 그 사실을 결과 보고에 적고 넘어간다. 서버가 제외한 경로의 파일만 물은 실행도 의심으로 찍힌다(확장자로는 경로 제외를 알 수 없다) — 이것도 적고 넘어간다.
2. 워커 보고의 `symbol tools: not used - <사유>` 줄(과 `[symbol tools: unavailable - <사유>]`) — 사유가 도구 없음 · 서버 오류면 배선(서버 활성 · 대상 트리 · 언어 목록)을 고친다. 그런 줄이 없으면(틀에 자리가 없으면 워커가 쓰지 않는다) 배선 의심으로 보고한다.

## exit 2 일 때 볼 것

1. 작업 폴더가 없는 세션에서 상태 기록 없이 돌렸다면 — 세션의 상태를 상태 기록 꼴의 한 줄(`Serena: active <트리> @<sha> (languages: …)` · `[Serena 미사용 — <사유>]`)로 임시 파일에 적어 `--tools-md` 로 넘겨 다시 돌린다. 화면에 알린 `[선택 도구] Serena …` 줄은 그 꼴이 아니라 읽지 못한다(`UNRUN`). 심볼 서버가 없는 머신이면 `[Serena 미사용 — <사유>]` 줄이 되고 그 실행은 `MCP_FALLBACK` 으로 끝난다.

## 재지 않는 에이전트

- 메모리 큐레이터(`memory-curator`)는 재지 않는다 — 메모리 회상이 일이라 심볼 호출 0 이 정상이다.

## 종료 훅 훑기

- 종료 훅 훑기도 같은 판정 함수로 실행마다 같은 낱말을 기록하고, 의심이면 알림 한 줄(`의심 N (<실행> <낱말>, …)` · 이 문서의 경로를 함께 적는다)을 띄운다 — 플러그인의 `hooks/hooks.json` 이 종료 훅을 `--audit-only` 로 등록해 설정 항목 없이 설치한 머신마다 돌고, 막는 것은 여전히 선택이다(`docs/completion-gates.md` § 종료 훅 훑기).
- 훑기는 이 플러그인이 설치되기 전에 끝난 실행(실행 기록 파일의 가장 늦은 수정 시각이 플러그인 루트의 `.claude-plugin/plugin.json` 수정 시각보다 이르다)을 판정하지 않는다 — 해당 없음으로 사유와 함께 기록하고 알리지 않는다(업데이트 직후 옛 정의로 돈 실행이 고칠 수 없는 경보를 내지 않게). 그 파일을 못 읽거나 시각이 미래면 경계 없이 판정한다. 손으로 돌리는 점검(`--wf` · `--direct`)은 이 경계를 쓰지 않는다.
